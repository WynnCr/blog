Most screen time tools assume you're on macOS or Windows, and the ones that
exist for Linux tend to be tied to a specific desktop environment. I run
[Niri](https://github.com/YaLTeR/niri), and I wanted something that:

- tracked focused windows, not just "time since login"
- stored everything locally, in a format I could query myself
- had a dashboard I'd actually open, instead of a JSON file I'd forget about

That turned into ghost-watch: a small daemon that listens to Niri's IPC
socket, logs window focus events to SQLite, and ships with an FTXUI
dashboard for looking at the data.

## Why SQLite

I didn't want a background service that eats memory just to hold state in
a hashmap. SQLite gave me a queryable log for free, and `sqlite3` on the
command line is a perfectly good ad-hoc dashboard while the real one is
still being built.

```go
func logFocusChange(db *sql.DB, window WindowInfo) error {
    _, err := db.Exec(
        `INSERT INTO sessions (app_id, title, started_at) VALUES (?, ?, ?)`,
        window.AppID, window.Title, time.Now().Unix(),
    )
    return err
}
```

## The dashboard

FTXUI-style terminal dashboards are underrated. You get a real UI —
scrollable lists, bar charts, keyboard navigation — without dragging in a
browser or an Electron shell just to look at your own data.

## What's next

Packaging is the current bottleneck. I want this to be a single Nix flake
away from running on anyone's Niri setup, not just mine.
